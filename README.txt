Español Fácil — تطبيق تعلّم الإسبانية

المحتويات:
- index.html: التطبيق
- manifest.webmanifest: إعدادات التثبيت
- sw.js: التخزين المؤقت للعمل دون إنترنت بعد أول زيارة
- icon-192.png و icon-512.png: أيقونة التطبيق

التثبيت على Android مجاناً:
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. من Settings > Pages اختر Deploy from a branch ثم main و /root ثم Save.
3. انتظر رابط الموقع الذي ينتهي بـ github.io.
4. افتح الرابط في Chrome على هاتف Android.
5. من قائمة ⋮ اختر Install app أو Add to Home screen.
6. افتح التطبيق مرة واحدة مع الإنترنت؛ بعدها يمكن فتح الصفحات المخزنة دون اتصال.

ملاحظات:
- الاستضافة عبر GitHub Pages مجانية للمستودعات العامة.
- النطق يعتمد على أصوات الإسبانية الموجودة في الهاتف/المتصفح وقد يحتاج تنزيل صوت إسباني من إعدادات Android.
- التقدم محفوظ محلياً على نفس الجهاز والمتصفح.
- هذا إصدار أولي قابل للتوسعة، ومحتوى الدروس حالياً تمهيدي وليس منهجاً كاملاً حتى B2.
